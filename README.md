## Deprecations

All versions below serie 5 are considerated to be deprecated and nop longer maintained.

## Technologies

Current version of the website is built with plain HTML and JS. The upcoming version is being developed with Next.js

## Local Run

- To run the website locally, you need to have Flutter installed.
- Following command will run the website locally on your machine and open with Google Chrome on port `3000`.

```bash
cd serie5/lukecreated-web
npm run dev
```

## Deployment

- run following command for build:

```bash
cd serie5/lukecreated-web
npm run build
```

- commit and push to the repository.
